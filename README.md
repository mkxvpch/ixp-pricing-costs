## IXP 专线是什么，为什么价格能便宜一半

传统 IPLC/IEPL 专线是“点对点”的物理电路，入口带公网 IP，你从家里、从办公室直接拨进去就行。运营商为这条独享电路、这个公网入口和高防能力收的钱，最后都会体现在月付里。

IXP 专线换了个思路：**入口不走公网，只挂在云厂商的交换内网里**。MKCloud 对这条规则写得很直白：

> 该产品为云厂 BGP 网络优化入口，仅允许云厂 BGP 网络连入（阿里云国内全网、腾讯云国内全网、百度云国内全网、火山云华东、华为云华东、UCloud 华东等），需要云厂 BGP 网络作为前置搭配使用。

换句话说，你要自己先有一台阿里云、腾讯云这类大厂的国内服务器做“前置”，流量先进前置，再从云厂内网进入专线入口。因为服务商省掉了公网入口 IP、公网暴露面和相应的高防成本，价格才能压下来；代价则是前置的部分由你自己搭。

顺带一提，在 MKCloud 的购买页里，这个产品挂在“上海—日本 IPLC 专线”分类下，网络选项选“上云互联优化入口(IXP)”，出口是日本 BGP。买的时候别选混了。

## 别忘了前置服务器的钱：IXP 专线的真实成本

这是很多人搜价格时最容易漏掉的一项。IXP 入口只收云厂 BGP 流量，所以你必须先买一台国内大厂云做前置，这笔钱完全在专线月付之外。

账其实不难算。以腾讯云官方文档页在售的 200M 锐驰型轻量服务器为参考，200Mbps 峰值、不限流量，月付 40 元起。拿它当前置，沪日 IXP 2TB 档的总成本约是 268 + 40 = 308 元/月，仍明显低于 IPLC 同档的 568 元。延迟方面，有 IX 用户在论坛发帖反馈，阿里云/腾讯云的广州轻量到 IX 入口的延迟大约在 8ms 上下，火山云能做到 3ms 左右，整体比传统专线端到端高 10ms 上下——对多数跨境业务场景，这笔账依然划算。

前置选型有两个坑要提醒。一是轻量服务器的“200M”是峰值带宽，且论坛里有用户反馈存在云厂商对个别账号限速的例子，对带宽敏感的话要有心理预期；二是前置本身没有专线那种高防，业务完全暴露在公网上的是你的前置机，防护得自己做。

3. **合规红线很明确。** 所有产品需中国身份信息实名，禁止机场等违法违规用途，也禁止二次转售和共享产品，违反会被清退且不退款。IX 产品没有公网入口、不容易被扫到，不等于可以拿去乱用。

## 购买与部署流程长什么样

整个流程比传统专线多一步前置配置，梳理下来是五步：

1. 准备一台允许范围内的云厂国内服务器（阿里云/腾讯云/百度云/火山云华东/华为云华东/UCloud 华东）做前置，安全组放行到专线入口的流量。
2. 在 [👉 MKCloud 购买页](https://bit.ly/MKCLoud) 选择地区“上海—日本”、网络“上云互联优化入口(IXP)”，选好档位和系统，完成实名后支付。有优惠码记得在购物车填写。
3. 开通后拿到入口地址和登录信息，用 SSH 或 RDP 连上专线 VPS。
4. 在前置机上做端口转发或隧道，把前置流量引到专线入口；业务程序跑在专线 VPS 上，从海外出口（日本 BGP）向外访问。
5. 用 iperf 或实际业务压一轮测速，确认前置带宽没有被限制，再决定是否扩大档位。

注意：海外出口只负责向外访问，不接受外部连入，这个方向别搞反了。

## 什么人适合 IXP，什么人老实买 IEPL/IPLC

基于价格和结构，判断其实不难做。

**适合 IXP 的**：已经手上有大厂云服务器、对成本敏感、目标方向是日本出口、流量在 1TB~6TB 区间的个人开发者和中小团队。166 元拿 1TB 跨境专线流量，这个价格在传统专线里确实找不到。

**适合传统 IPLC/IEPL 的**：没有也不打算维护前置机的、对端到端延迟极端敏感的（比如广港 1~2ms 的场景）、需要开箱即用省事的，以及担心前置政策变动的用户。传统线路贵出来的钱，买的就是“少一层依赖”。

## 常见问题

**IXP 专线为什么这么便宜？** 入口挂在云厂交换内网、不走公网，服务商省掉了公网 IP 和公网侧防护的投入，这部分让利到了价格里。前置的成本和防护责任转移给了用户。

**没有大厂云服务器能直接买吗？** 不能。入口只允许阿里云、腾讯云、百度云、火山云华东、华为云华东、UCloud 华东等云厂 BGP 网络连入，这是产品规则，不是建议。

**想省一点，有什么办法？** 第三方测评整理的 88 折优惠码 MK-8.8 可以在对应的 IEPL/IPLC 套餐上使用，以登录后台实际显示为准；另外官方节假日偶有提交工单赠送临时流量的活动，多留意通知频道即可。
